# GitHub被Agent Skills刷屏：AI编程开始卷操作手册了！

> AI编程生态下一层增量不是又一个Agent，而是把团队流程、技能和规约变成可复用工程资产。

## 先看事实

- GitHub AI coding热度集中在openrig、OpenHands、claude-code、openclaw、iFixAi、TencentCloud/Octop等Agent与审计/编排项目。
- agent skills生态包括alirezarezvani/claude-skills、addyosmani/agent-skills、ComposioHQ/awesome-claude-skills、dotnet/skills等。
- K-Dense-AI/scientific-agent-skills把科学数据库与技能封装给研究型Agent使用。
- MCP、AGENTS.md、skills与插件把团队约束、工具和流程从聊天记录沉淀成可加载资产。
- Step 3.5查重：9月22写过Claude Code支持AGENTS.md，9月27脚本候选写过Skills生态；本篇保留但换成“操作手册成为生产资料”的工程组织角度，标记中重复换角度。

## 开源热度从Agent本体转向技能层

过去AI编程项目最容易火的是“又一个能写代码的Agent”。现在热度开始分散到openrig这样的多Agent编排、iFixAi这样的审计工具、各种skills和plugins集合。开发者慢慢发现：模型会写代码只是起点，真正决定产出的，是它有没有一套靠谱操作手册。

## Skills把经验变成可复用资产

一个团队摸索出来的发布流程、测试规范、设计系统、代码风格，如果只藏在老员工脑子里，Agent每次都要重新猜。Skills的价值是把这些隐性经验写成文件，让Agent在需要时加载。它不像一次性提示词，更像组织知识的接口。

## AGENTS.md和MCP让边界变清楚

AGENTS.md告诉Agent这个仓库怎么干活，MCP把外部工具和数据源接进来。二者合在一起，形成了“你能做什么、该怎么做、去哪拿工具”的说明书。AI编程的生产力，正在从模型参数迁移到流程标准化。

## 未来团队会维护自己的Agent手册库

最强的AI团队未必只买最贵模型，而是会维护一套自己的技能库：写PR、查日志、画图、做安全审计、跑回归、写发布说明。模型换了，技能还能复用；员工换了，流程仍然留下。这才是AI工程化真正的复利。

## 最后一句

GitHub热榜的变化很清楚：AI编程开始从“谁的Agent更聪明”转向“谁的操作手册更完整”。未来团队的AI生产力，可能就藏在一堆看似普通的skills、AGENTS.md和流程文件里。

## 一、一个共识正在形成

过去一周，从 Google I/O 刚落幕，到微软和 AMD 接连放出大动作，国内外 AI 圈呈现出一个强烈的共识：

**AI 正在从"对话聊天模式"全面转向"Agent（智能体）干活模式"。**

这不是某一家公司的战略，而是整个行业的转向。

让我们快速回顾一下过去几天发生了什么：

## 二、国际前沿：OpenAI、微软、LinkedIn 三连击

### 1. OpenAI Codex 推出"目标模式"

OpenAI 给 Codex CLI 加了个新命令：`/goal`。

你给它设一个目标，它就一直跑，跨多轮不丢上下文，**不达目的不罢休**。

有人测试发现：博士生需要 80 小时完成的任务，Codex 不到 2 小时跑完了。效率提升 **40 倍**。

这代表着什么？

**AI 从"你问我答"变成了"你定目标我死磕"。**

### 2. ChatGPT 推出个人财务功能

ChatGPT Pro 用户现在可以连接银行账户，ChatGPT 会直接生成财务看板，帮你分析消费、规划预算。

**AI 开始介入你真实的财务生活了。**

### 3. 微软+安永：10 亿美元投向企业 AI 落地

微软和安永宣布五年内联合投资超过 10 亿美元，目标是帮助企业把 AI 从"试点"变成"大规模落地"。

重点领域：财务、税务、人力、供应链——**都是企业最核心的业务板块**。

### 4. LinkedIn：用 AI Agent 自动写 GPU 算子

LinkedIn 的开源项目 Liger Kernel 宣布引入 AI Agent 自动化工作流。

过去适配新模型需要稀缺的 GPU 算子专家手写代码，现在 AI 自己就能干了。

**用 AI 制造更好的 AI，这个循环开始加速了。**

---

## 三、国内进展：李开复×苏姿丰 + 灵玑OS

### 1. 李开复对话苏姿丰：Agent 诸神之战开启

在上海 AMD AI 开发者日上，零一万物 CEO 李开复抛出了一个判断：

> "从 2026 年起，AI 开始替代的将不是岗位，而是**整个部门**。"

他认为，"DRI（直接责任人）+ 多智能体"将重构未来企业的基础单元。

单纯拼模型参数的时代结束了，**谁的 Agent 能落地、能干活、能交付结果**，谁就赢。

### 2. 灵玑OS：国内首个智能体基础设施

北京发布了"灵玑OS"——国内首个开源开放的 AI 智能体共性基础设施。

目标是解决智能体产业的四大痛点：
- **连不上**（不同厂商的 Agent 无法互通）
- **干不成**（多智能体协作缺乏机制）
- **管不住**（治理和审计能力不足）
- **控不稳**（生产环境可靠性不够）

**中国开始在智能体的"底座"上布局了。**

## 四、为什么是现在？

为什么 Agent 突然成了行业焦点？

几个关键变化：

### 1. 模型能力到位了

GPT-4、Claude 3、Gemini 这一代模型的推理能力、上下文长度、工具使用能力，已经足以支撑复杂的 Agent 任务。

### 2. 成本打下来了

DeepSeek 等厂商把模型训练和推理成本打骨折，让 Agent 大规模运行成为可能。

### 3. 场景想清楚了

企业开始明白，聊天机器人只是开胃菜，**真正的价值在于让 AI 接管业务流程**。

### 4. 基础设施在建设了

从 OpenAI 的 Tool Use，到 Anthropic 的 Computer Use，到灵玑OS——Agent 运行的基础设施正在成熟。

---

## 五、这对我们意味着什么？

如果你是开发者：
- **学会构建 Agent**，不只是调 API
- 理解**多智能体协作**的设计模式
- 关注**工具调用、环境交互、记忆管理**这些 Agent 核心能力

如果你在企业工作：
- AI 不再只是 IT 部门的事，它正在进入**业务核心**
- 学会**和 Agent 协作**，可能比学会写代码更重要
- 关注你所在行业的 Agent 落地案例

如果你是创业者：
- 模型层的机会窗口在收窄，**应用层和工具层**的机会在打开
- 找到一个**具体场景**，让 Agent 真正解决问题、交付结果
- 考虑如何与灵玑OS等开源生态协作

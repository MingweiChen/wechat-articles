深度分析

300亿 vs 250亿
Anthropic 营收反超 OpenAI

硅谷正在上演最狠权力交接

18个月前，Anthropic 的年收入还不到 OpenAI 的六分之一。现在，这家"叛逃者"的营收已经反超老东家。这不是偶然。

01 数字不会说谎，但会让人窒息

先看一组让人血压升高的数据：

• 2024年初：Anthropic ARR 10亿美元，OpenAI 60亿美元

• 2025年中：Anthropic ARR 45亿美元，OpenAI 130亿美元

• 2026年4月：Anthropic ARR 300亿美元，OpenAI 约250亿美元

没看错。Anthropic 在18个月内完成了30倍增长。Salesforce 花了20年才做到300亿年收入，Anthropic 用了不到3年。

更刺激的是 CEO Dario Amodei 在开发者大会上的"凡尔赛"发言：

"我们原本计划应对10倍增长，结果来了80倍。这太疯狂了，我们根本扛不住。"

计划10倍，实际80倍。这不是增长，是失控。

如果你觉得这是泡沫，再看一个数据：企业客户中年付费超过100万美元的，从2月的500家翻倍到4月的1000家。Fortune 10 里有8家在用 Claude。这不是散户在买单，是华尔街的钱在投票。

02 Claude Code：那个让程序员上瘾的"毒品"

Anthropic 逆袭的核心武器，叫 Claude Code。

这不是一个聊天机器人，是一个自主编程代理。它能读代码库、制定计划、调用开发工具执行任务、评估结果、自动调整策略。开发者只需要设定目标，剩下的它自己干。

一些令人不适的事实：

• Claude Code 发布6个月，ARR 突破10亿美元

• 2026年2月，ARR 达到25亿美元，业务订阅量翻了4倍

• 全球 GitHub 公共提交中，4%由 Claude Code 生成

• Anthropic 内部的代码，大部分现在由 Claude 自己写

最后一条值得细品：Anthropic 正在用自己的产品开发自己的下一代产品。这是一个自我加速的飞轮——竞争对手没有同等产品就无法复制这个循环。

开发者平均每周花20小时和 Claude Code 一起工作。这个数字说明一件事：它不是工具，是同事。

表面是代码助手，本质是生产力重新定义。

03 OpenAI 在哪里失速？

OpenAI 不是在原地踏步。它的 ARR 从2024年的60亿涨到了2025年底的200亿，今年预计能到250亿。增长率是健康的，用户量是碾压级的——ChatGPT 周活超过8亿。

但问题在于：用户多不等于钱多。

Reuters 的分析师说了一句扎心的话：

"关键指标不是用户数，而是 token 消耗量。一个程序员的编程任务消耗的 token 是普通聊天的10-50倍。100万个问'今天天气怎么样'的用户，不如1万个在用 AI 写代码的开发者。"

Anthropic 的战略从一开始就不是追求用户规模，而是追求高价值用户密度。Claude 的 API 收入占总收入的70-75%，按 token 计费，用得越多付得越多。而 OpenAI 的收入结构更依赖订阅，天花板更低。

另一个问题是产品节奏。Anthropic 在2025年5月发布 Claude Code，迅速迭代。OpenAI 同期在干什么？发布了 Sora 视频生成，搞了 GPT-4o 的语音模式，都是消费者向的"炫技"产品。炫技能换来 Twitter 热搜，换不来企业合同。

如果 Anthropic 选择了窄路深挖，OpenAI 就是在宽路上走马观花。

04 会计游戏：这些数字可能都不准

在你被300亿这个数字震撼之前，有个细节必须说清楚。

Anthropic 和 OpenAI 的营收统计方法不一样。

两家公司都通过云服务商（AWS、Azure、Google Cloud）分销模型，云厂商会抽成约20%。OpenAI 按净收入报告——扣掉给微软的分成之后的数字。Anthropic 按毛收入报告——扣之前的数字。

Khosla Ventures 的合伙人 Ethan Choi 在3月直接点破：

"如果两家公司都上市，我不知道 SEC 会怎么处理这两种完全不同的会计处理方式。"

换句话说，如果 Anthropic 用 OpenAI 的算法，它的营收数字会低一截。如果 OpenAI 用 Anthropic 的算法，它的数字会高一截。

这不意味着 Anthropic 的增长是假的。增长趋势是真的，只是绝对数字存在"注水"空间。投资者和媒体在没有统一口径的情况下直接比较两个数字，本身就是苹果比橘子。

但市场不在乎这些细节。钱在流向 Anthropic，估值在攀升，IPO 箭在弦上。感知即现实。

05 这场逆转对行业意味着什么？

Anthropic 的崛起正在重写几条行业规则：

1️⃣ To B 比 To C 更值钱

ChatGPT 有8亿用户，Claude 的用户量可能只有它的零头。但 Anthropic 的企业客户数量已经超过 OpenAI——Ramp 的支出数据显示，34.4%的企业在付费使用 Anthropic 服务，OpenAI 是32.3%。用户规模不再是唯一指标，付费意愿和使用深度才是。

2️⃣ 代理（Agent）是下一个战场

Claude Code 的成功证明了一件事：未来的 AI 产品不是回答问题的聊天框，而是替你干活的代理。谁能让 AI 真正接管工作流，谁就能锁定企业预算。

3️⃣ 安全叙事可以是商业武器

Anthropic 从创立第一天就把"AI 安全"写在公司使命里。这曾被认为是理想主义包袱，现在成了销售优势。企业客户——尤其是金融、医疗、政府——需要一个"负责任"的供应商。Anthropic 把安全做成了品牌溢价。

写在最后

18个月前，Anthropic 是 OpenAI 的"叛逃者"，是硅谷的 underdog。今天，它的估值接近万亿美元，营收增速是科技史上最快之一，正在逼近 IPO。

OpenAI 不会消失。它有微软的资源、有 ChatGPT 的用户基数、有 Altman 的光环。但先发优势不等于持久优势，用户规模不等于商业壁垒。

如果你是投资人，你会押注那个有8亿用户但增长放缓的巨头，还是那个18个月翻30倍、企业客户在排队签约的挑战者？

答案不重要。重要的是，AI 行业已经进入下半场，而规则正在被改写。

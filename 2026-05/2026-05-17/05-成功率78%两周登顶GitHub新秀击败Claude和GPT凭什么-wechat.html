OpenHands：开源 Agent 框架的逆袭

一个开源项目，两周内把 Anthropic 和 OpenAI 都挤下去了。

GitHub Trending 榜单很少出现这种场面：一个名不见经传的开源项目，在短短两周内从默默无闻冲到榜首，背后没有硅谷大厂背书，没有天价融资造势，只有一群执着于"让 AI 真正写代码"的开发者。

这个项目叫 OpenHands。

而它刚刚在 SWE-bench——全球公认最难的 AI 代码能力测试——上交出了一份让所有人侧目的成绩单：78% 的任务解决率，超越了 Anthropic 的 Claude，也超越了 OpenAI。

01 数据不会说谎：78% 意味着什么

先说背景。

SWE-bench 是普林斯顿大学推出的基准测试，被称为"AI 程序员的高考"。它从 Django、scikit-learn、SymPy 等 12 个顶级 Python 开源项目中抽取了 2294 个真实 Bug，要求 AI 不仅要定位问题，还要写出能通过所有测试的补丁代码。

这不是让 AI 写个 Hello World，而是让它修复生产环境里的真实故障。

2023 年 10 月，SWE-bench 刚推出时，最强的 Claude 2 只跑出了 1.96%。没错，100 个 Bug 只能修 2 个。

一年半后的今天，OpenHands 的成绩是 78%。

2026 年 5 月最新榜单：

🥇 OpenHands (Claude Opus 4.5) — 77.6%

🥈 Claude Code (Opus 4.7) — ~78%

🥉 OpenAI Codex Agent (GPT-5 Pro) — ~76%

④ Cursor Agent (Sonnet 4.6) — ~67%

⑤ Devin (Cognition AI) — ~58%

数据来源：SWE-bench 官方排行榜与 Presenc AI 2026 年度报告。

关键点来了：OpenHands 用的是开源框架 + Claude 模型，而 Claude Code 是 Anthropic 的官方产品。同样的模型，OpenHands 的工程化实现打出了相当甚至更高的分数。

💡 Agent 框架的工程能力，可能比底层模型更重要。

02 OpenHands 凭什么赢

所有人都在卷模型参数、卷上下文长度、卷推理能力。OpenHands 卷的是工程。

▎CodeAct：让 Agent 像程序员一样思考

传统 AI 编码工具的思路是：你问一句，我答一句。ChatGPT 模式。

OpenHands 不一样。它的核心 Agent 架构叫 CodeAct——不是生成代码片段，而是让 AI 像真正的程序员一样工作：

✅ 执行 bash 命令：ls、grep、git，该用什么用什么

✅ 运行 Python 代码：不是建议你运行，而是直接运行

✅ 浏览网页：需要查文档？自己去查

✅ 编辑文件：不是给你 diff，而是直接改

这是一个能自己动手的 Agent，不是一个只会说话的 Chatbot。

▎沙箱隔离：安全地让 AI 放手干

让 AI 执行代码是危险的。万一它 rm -rf / 怎么办？

OpenHands 的解决方案：Docker 沙箱。每个 Agent 运行在隔离的容器里，想删库？请在你自己的沙箱里删。

这让团队敢于把 OpenHands 部署在生产环境，让它直接处理 GitHub Issues、自动提交 PR。

▎推理时扩展 + Critic 模型：让正确率翻倍

OpenHands 团队在论文中披露了一个关键技术：推理时扩展（Inference-Time Scaling）。

简单说，就是让 Agent 对同一个问题跑多次，然后用一个专门训练的 Critic 模型来挑选最佳答案。

他们用时间差分学习（TD Learning）训练了一个基于 Qwen 2.5 Coder 32B 的评分模型，从单次尝试的 60.6% 准确率，提升到五次尝试的 66.4%，最终达到 77.6%。

同样的底层模型，不同的工程方法，结果天差地别。

05 这意味着什么

一个有趣的事实：OpenHands 的核心团队来自卡内基梅隆大学，不是硅谷大厂。

他们没有 Anthropic 的顶级人才密度，没有 OpenAI 的算力资源，没有 Google 的数据飞轮。

但他们做出了一个在最硬核基准测试上打平甚至超越巨头的开源项目。

🎯 这给所有 AI 开发者传递了一个信号：
Agent 时代的竞争规则变了。

模型能力的天花板在被逼近，差异化的空间从"谁的模型更强"转向"谁的工程更好"。

• 更好的工具链设计

• 更聪明的多次推理策略

• 更安全的执行环境

• 更灵活的扩展架构

这些"脏活累活"，才是下一阶段 AI 编程工具的核心战场。

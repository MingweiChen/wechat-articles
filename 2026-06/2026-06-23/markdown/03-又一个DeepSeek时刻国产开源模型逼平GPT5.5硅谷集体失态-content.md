# 又一个 DeepSeek 时刻，但这次硅谷紧张的不是跑分

Vercel 的 CEO Guillermo Rauch 在 X 上只写了四个词：**This changes things（这事变了）**。

他的原话是「genuinely impressed, almost shocked」——真的被震到，几乎是吓到。一个云平台公司的老板，平时见惯了各种模型发布，会用「shocked」这个词，本身就不寻常。

让他失态的，是一个中国开源模型。Z.AI（前身智谱）6 月 13 日放出 GLM-5.2，权重免费下载，MIT 协议，没有任何使用限制。消息出来后，智谱的港股一度单日跳涨。上一次中国模型让硅谷出现这种集体反应，还是一年多前的 DeepSeek。

但如果你只盯着「中国模型又追上来了」这条线，会错过这次真正的看点。

## 几个一线建设者，不约而同说了同一句话

值得注意的是，这次发声的不是吃瓜群众，是一批每天靠 AI 吃饭、自己在搭系统、上产品的人。他们的判断更值钱，因为他们要为自己的判断买单。

> Box CEO Aaron Levie：开源和闭源的差距「保持收窄而不是拉大」，这意味着更多价值可以建在 AI 之上——这对整个应用层都是好事，包括前沿实验室自己。

> Answer.AI 与 Fast.AI 联合创始人 Jeremy Howard 说得更直接：GLM-5.2 是「a marvel（一个奇迹）」，至少和 Claude Opus 4.8、GPT-5.5 一个水平。他特意点出跑分图表抓不到的东西：分寸感、判断力、可靠的长上下文处理。

> 前 Meta、Google DeepMind、微软副总裁 Mat Velloso 花了一整天用它，结论是：「第一个能当日常主力的开源模型。things are not going to be the same。」

这四个人，Rauch、Levie、Howard、Velloso，背景不同、立场不同、彼此没串供，却在没人组织的情况下收敛到同一个反应。这种「自发的共识」，比任何一张 benchmark 截图都难反驳。

## 真正变了的东西，叫「长程任务」

跑分当然也好看。GLM-5.2 在 SWE-bench Pro 上拿到 **62.1 分**，压过 GPT-5.5 的 58.6；在衡量长程任务完成度的 FrontierSWE 上，跟 Claude Opus 4.8 只差不到一个百分点。综合的 Artificial Analysis 智能指数 v4.1 拿到 51 分，全球第四，在开源阵营里领先第二名整整七分。

但分数不是重点。重点藏在 Howard 那句「可靠的长上下文处理」里。

这一代模型的能力上下文窗口从 20 万词元拉到了 **100 万**，而且 Z.AI 专门做了长上下文训练。配合上面那些跑分，它指向一个新的能力边界——**模型正在从「即时问答」进化到「能像人一样连续工作几小时，把一个完整工程从头跑到尾」**。

这件事其实不是「又一个更聪明的聊天机器人」，而是另一种东西。即时问答是一来一回，你问它答；长程任务是你交代一个目标，它自己规划、自己执行、自己联调、自己处理中途出现的岔子，几个小时后给你一个能跑的结果。前者是工具，后者更像一个能托付活的同事。

为什么这正好是硅谷最敏感的那根神经？因为闭源大厂过去最值钱、利润最厚的那块，恰恰就是「复杂的、需要长时间推理的、企业愿意为之付高价的」活。

## 价值正在从「模型层」往「应用层」漏

这里有个微妙的点，Levie 那句话其实说破了。

闭源模型的商业模式是「你依赖我」。消费者离不开供应商，供应商才能截留足够多的价值，这对烧着几十亿美元建基建、又被投资人盯着要营收增长的公司来说，是命根子。

> 一旦一个开源模型「足够好 + 足够便宜 + 够用」，它要做的不是打败 GPT，而是把闭源大厂那道最赚钱的护城河悄悄填平。

顺这条线推下去：当开源模型能以接近前沿的质量处理规划、执行和 agent 工作流，那些在 AI 上面搭产品的公司，就可以在几乎不损失性能的前提下重新配置自己的模型栈，便宜的活交给开源，最难的推理和编排留给闭源。

价值不会消失，但它会从「谁的模型最强」这一层，往下漏到「谁能把模型用得最好」那一层。这才是「应用层」三个字的分量。前沿实验室仍然守得住最硬的那部分，可「什么活路由到哪」的算盘，已经被重新打过了。

## 把账算给你看

让这套逻辑从口号变成行动的，是价格。

| 项目 | GLM-5.2 |
|---|---|
| 输入价格 | 约 1.4 美元 / 百万词元 |
| 输出价格 | 约 4.4 美元 / 百万词元 |
| Coding 套餐 | 约 18 美元 / 月起 |
| 开源协议 | MIT，权重 Hugging Face 免费下载 |

这是闭源前沿模型的一个零头。**价格差已经在驱动真实的迁移决策**：此前就有创业公司 CEO 公开说，把生产负载从闭源换到中国开源模型后，省下了数百万美元。

还有一个常被忽略的隐性价值：稳定性。最近一轮出口管制行动让某些前沿模型在全球范围内下线，对一家把核心业务架在 AI 上的公司来说，「会不会因为一纸政策决定被掐断」本身就是风险。MIT 协议的开源权重，从「锦上添花」变成了「保命选项」。

## 这次和上次有什么不一样

DeepSeek 那一次，硅谷被惊到的是「成本」，原来用这么少的钱，也能逼近 o1。投资人开始怀疑，那道领先优势是不是没看上去那么稳。

GLM-5.2 这一次，惊到他们的不是便宜，而是「够用到可以当主力」。不同公司、不同模型、不同的 benchmark 类别，但故事的形状一模一样：一个本以为还落后一截的对手，突然递到了你面前一个你不得不认真用的东西。

值得一提的是 Z.AI 的节奏。这家公司今年 1 月完成港股 IPO，自从上了某份实体清单后，一直在零英伟达硬件的条件下运行，却维持着大约每六周一个重要模型的发布频率。**当最先进的算力被卡住，逼出来的往往是另一条路上的效率**——同样的硬件足迹（744B 总参数、每次推理激活 400 亿），GLM-5.2 相比上一代的提升几乎全部来自训练改进，而不是堆规模。

所以当 Vercel 的 CEO 说「this changes things」，他大概不是在说一个跑分。他是在说，模型层这块蛋糕的吃法，可能真的要变了。

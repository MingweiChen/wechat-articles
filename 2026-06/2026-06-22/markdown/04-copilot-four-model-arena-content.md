# 同一个编辑器里，四家模型开始贴身肉搏

光标停在一行没写完的函数后面。我按下 `Tab`，灰色的补全跳出来，顺手收下。

这一秒，我没意识到一件事：刚才那段代码，到底是 OpenAI 写的，还是 Anthropic、是微软自研的模型、还是谷歌的 Gemini，我根本不知道，也没人告诉我。

**编辑器右下角那个不起眼的下拉框里，现在挤着四家公司的模型。** 它们在抢同一个位置——抢我下一次按 `Tab` 时，到底由谁来接管这一行。

过去两年，模型之间比的是排行榜上的分数。而 Build 2026 之后，战场悄悄换了地方：从「谁的跑分高」，挪到了「谁是那个默认选项」。

## 现场：微软一口气端出七个自家模型

Build 2026 上，微软没只发一个模型，而是端出了一整排：**七个自研模型**，其中专门为 GitHub 场景调校的 `MAI-Code-1`，外加一个主打低延迟的 `Flash` 小号。

几乎同一时间，谷歌的 `Gemini 3.5 Flash` 也滑进了 Copilot 的模型选择器。

把镜头拉远看这个下拉框，会发现一个有点荒诞的画面：

> 一个编辑器的补全菜单里，OpenAI、Anthropic、微软、谷歌四家同框。开发者每敲一次回车，都是在一群互为对手的供应商里盲选后端。

这里有个微妙的点。微软是 OpenAI 最大的投资方，按常理它该把流量往 OpenAI 那边导。可它转头把自研模型摆在了同一个菜单、同一排选项里，跟自己投的公司面对面抢用户的每一次点击。

**平台方第一次这么公开地，既当裁判又当选手。**

## 为什么入口比能力更值钱

很多人看到这条新闻的第一反应是：哦，又多了几个模型可选，挺好。

但顺着这条线往下推，会得到一个不太一样的结论。

对一个普通开发者来说，模型早就不是一个「品牌」了，而是编辑器背后一段看不见的后端逻辑。绝大多数人不会去逐一对比七个模型的参数表，他们只会用那个默认选中的。

| 旧战场 | 新战场 |
|---|---|
| 模型是台前的「明星产品」 | 模型是幕后的「无名后端」 |
| 用户冲着某个模型而来 | 用户冲着编辑器而来，顺手用了某个模型 |
| 比的是发布会和跑分 | 比的是谁占住了默认下拉框 |

一旦模型退到幕后，**谁握着分发入口，谁就握着流量的总开关。** 你的模型再强，挤不进那个下拉框，开发者一辈子也不会按到你。

这就是微软真正在下的那步棋：它不需要自研模型每一项都打赢 OpenAI，它只需要让自研模型出现在那个所有人都会点到的位置上。位置本身，就是筹码。

这条逻辑在互联网历史上反复上演过。当年浏览器的默认搜索引擎、手机的预装应用，都是同一个剧本——能力相近时，决定胜负的从来不是产品本身多强，而是它有没有站在用户的必经之路上。**模型这一仗，正在被打回这个老规律里。**

换个角度想，这对开发者其实是双刃剑。选项变多了，看起来是自由；但绝大多数人最终还是只用默认那个，真正的选择权，悄悄从用户手里，回到了那个决定「默认指向谁」的平台手里。

## 评判标准也跟着变了

战场换了地方，裁判的尺子也换了。

过去刷榜，刷的是一道道孤立的算法题、一段段几十行的小函数。但放进真实编辑器里，这些指标基本失效，没有哪个工程师的日常是做奥数题。

于是新的评判标准浮出水面：像 **SWE-Bench Pro** 这种要在真实代码仓库里跨文件改 bug 的任务，像 **MCP-Atlas** 这种考模型会不会调用外部工具、查文档、跑测试的能力。

> 衡量一个模型好不好用，不再看它单题答得多漂亮，而看它能不能在一个几十万行的真实项目里，调对工具、改对地方、不把别处搞坏。

这其实是个信号：模型能力的竞争，正在从「会不会答题」滑向「会不会干活」。而干活这件事，恰恰是在编辑器里、在工具链里发生的——又一次绕回了入口。

顺这条线推下去会发现一个闭环：评判标准越靠近真实工程，模型就越离不开编辑器这个运行环境；越离不开环境，掌握环境的平台方话语权就越大。**裁判的尺子和选手的赛场，被同一家公司握在了手里。**

## 这盘棋里，OpenAI 站在哪

把前面几条线串起来，会看到一个反直觉的画面。

表面上，这是「平台变开放了，给开发者更多选择」。**实际上，这是微软在用平台位置，稀释自己对单一供应商的依赖——包括它自己投的 OpenAI。**

逻辑并不复杂：

- 把 OpenAI、Anthropic、谷歌、自研模型全摆进同一个菜单，没有谁是不可替代的；
- 哪天某家涨价、出问题、或者关系生变，微软随手就能把默认项切到别家；
- 自研模型摆在那儿，本身就是一张随时能加注的底牌。

对一个深度绑定了某家供应商的平台来说，最贵的不是钱，是「离不开」。而把对手和自己人塞进同一个下拉框，恰恰是把「离不开」一点点拆成「随时能换」。

这一手，对 OpenAI 来说滋味复杂：最大的金主，正在亲手为它培养替补。

## 写在最后

下次你在编辑器里按下 `Tab`，不妨多看一眼右下角那个下拉框。

那里没有发布会的灯光，没有刷屏的跑分海报，只有一行行小字排在一起。但模型竞争真正的胜负，已经从聚光灯下的舞台，搬到了这个没人多看一眼的角落。

排行榜决定谁上头条，下拉框决定谁有饭吃。

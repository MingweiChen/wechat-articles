AGI 已经来了
只是没人放它进公司上班

 

一个卖数据底座的人说 AGI 已来,他盯的不是参数表,而是另一件事。

“我们认为 AGI 已经到了。AI 现在不缺智商,它够聪明了。问题是它还没真正渗进我们的组织。真正的问题是:怎么让它在公司里干活?”

说这话的不是某个赶着发系统卡的模型实验室,而是 Databricks 的 CEO Ali Ghodsi。6 月中旬,旧金山 Moscone 中心,他在自家 Data + AI Summit 主舞台上,当着三万多名数据从业者,把整个行业等了好几年的那句话,轻飘飘说成了过去式。

这句话的分量,在于说它的人是谁。实验室喊“AGI 快来了”不稀奇,他们的融资叙事就靠这个续命。但 Ghodsi 卖的不是模型,他卖的是数据湖仓,是企业放数据的那个底座。一个卖“地基”的人跳出来说 AGI 已来,他盯的不是参数表,而是另一件事:这玩意儿这么聪明了,为什么进了公司就变蠢?

Databricks 创始人兼 CEO Ali Ghodsi 在 Data + AI Summit 主舞台——一个卖「数据地基」的人，跳出来宣布 AGI 已来

智商不是瓶颈,这才是反直觉的地方

先把一个数字摆这儿:据斯坦福那门讲 AI 超级周期的课上 Ghodsi 自己引的数据,企业 AI 的概念验证(POC),大约 95% 跑不进生产。

模型在 benchmark 上能解奥赛题、能写代码、能通过律考,可一旦放进一家真实公司,它就开始干蠢事。如果模型真有 AGI 水平,这个失败率根本说不通。Ghodsi 的解释很冷静:不是模型笨,是它没有上下文。

“即便一个超级智能的模型,放进你公司也会干蠢事,因为它拿着的是一张残缺的地图。”

他打了个戳人的比方。每家公司里都有那么一个老员工,干了十五年、二十年,脑子里装着所有东西:哪条流程改过但从没写进文档,哪个客户群才会触发那个诡异的边缘情况,真正拍板时遵循的是哪条没人明说的潜规则。这个人的脑子,从没被搬进任何 AI 系统里。模型缺的不是智商,是这颗脑子。

这就是为什么 Ghodsi 把战场从“模型够不够强”整个挪走了。在他的坐标系里,AGI 落地卡在三道工程墙上,跟参数毫无关系:上下文(context)、成本(cost)、控制(control)。

第一道墙:让 Agent 真的“看见”生产数据

第一道墙：让 Agent 真的「看见」企业的真实生产数据，而不是开卷抄文档

这道墙最根本。模型再聪明,看不见公司的真实数据,就是个外人。

Databricks 这次甩出来的东西,几乎全冲着“让 Agent 安全碰到真实生产数据”这一个目标。它发了一套新架构,官方叫 Lake TAP(事务/分析一体化处理),核心一句话:让 AI Agent 能在数据湖里同一份数据上,同时读运营库和分析库,再跨着一大堆生产数据库去观察、推理、动手。配套还有个实时引擎,据联合创始人 Reynold Xin 现场演示,几万个 Agent 同时砸向同一个查询,延迟还能压在毫秒级,他说现有系统没一个能做到。

更值得琢磨的是 Genie 这条线。新发的 Genie One 底下挂了个叫 Genie Ontology 的“活上下文层”,持续从公司内外的业务数据里学,Ghodsi 把它类比成 Google 搜索的 PageRank,给企业数据做相关性排序。他给 Genie 下了句很狠的定义:

“Genie 是算出来的,别的 Agent 是背出来的。”

翻译过来就是:满大街的“企业 Agent”其实是套了层壳的检索增强,把文档塞进上下文窗口再让模型复述;而他要做的,是让 Agent 接上活的业务数据去现算。前者是开卷抄答案,后者是真懂这家公司。 这中间的差距,恰恰就是那个跑不进生产的 95%。

第二道墙:Agent 越多,利润越薄

营收暴涨、利润率却在缩水——Agent 用得越凶，Token 烧得越快，这是 Ghodsi 被问得最多的问题

这道墙最容易被忽略,但 Ghodsi 拿自家财报把它砸实了。

他告诉 CNBC,Databricks 年化营收同比涨了 80% 多,冲到 69 亿美元。漂亮。可下一句他话锋一转:利润率在缩水,因为客户开始成批成批地部署 Agent,把成本推上去了。

这里有个微妙的点,值得停一下。当一家公司告诉你它营收暴涨、同时利润率在掉,而原因是“客户用得太凶”,这说明 Agent 经济正撞上一堵真实的墙:Token 烧得太快。Ghodsi 自己也认:“每家公司都在为成本失控发愁,这是我们被问得最多的问题。”

所以他们端出 Unity AI Gateway,一个管控层,把安全、成本管理、Agent 监控捏在一起。说白了,当公司里跑着成千上万个 Agent、每个都在疯狂调用模型,你得有个收费站,知道钱花在哪、哪个 Agent 在空转。没有这道闸,Agent 进公司不是降本,是失血。

第三道墙:它要动手,你得拦得住

第三道墙：当攻防双方都换上 Agent，「以火攻火」——人盯告警的老办法已经不够看

模型聪明、看得见数据、成本也压住了,最后还剩一个最让企业睡不着的问题:你敢让它动手吗?

让 Agent 读数据已经够慌,让它在生产环境里采取行动(改库、发指令、回工单),风险是另一个量级。Databricks 给出的答案是给 Agent 装护栏,这次还是真金白银买的。6 月 16 日,它官宣收购 AI 安全运营平台 Panther,这是它在安全领域的第三笔并购。Panther 在 2021 年那轮融资后估值 14 亿美元,客户里有 Anthropic。Ghodsi 对 Reuters 把逻辑摊得明明白白:

“如果他们用 Agent 攻击你,你就得用 Agent 防守。以火攻火。”

他的判断是:AI 已经把攻击者钻漏洞的时间大幅压缩,老一套靠人工管告警的安全方式“已经死了”。当攻防双方都换上 Agent,人盯告警的速度根本不够看。

把三件事拎到一起看就清楚了:

• Lake TAP 解决“让 Agent 看见数据”

• Unity Gateway 解决“看住 Agent 花的钱”

• Panther 解决“在 Agent 动手时兜住安全”

三件产品,串的是同一根主线:怎么让 Agent 安全地碰公司真实生产数据并采取行动。这根线,就是 Ghodsi 眼里 AGI 落地的全部。

顺这条线推下去:红利不在模型层

把三道墙叠在一起,会浮出来一个比“AGI 来没来”更值钱的结论。

如果 Ghodsi 是对的,模型已经够聪明、卡点全在工程,那 AGI 的商业化红利就不在模型层。它会沿着一个老剧本往上爬:每一层基础设施被做成标准品,价值就往上面那一层迁移。Ghodsi 自己捋过这条历史线:PC 时代 IBM 称王,操作系统层被微软拿走,虚拟化归了 VMware,云基础设施归了 AWS。每一层一旦商品化,溢价就让给上面一层。他赌模型层也会这么压到接近零毛利,因为开源追得比多数人想象的快。真正能赚钱的,是离“公司怎么真实运转”最近的那一层。

这就解释了一家卖数据底座的公司,为什么敢抢在实验室前面宣布 AGI 已来:按这套逻辑,谁先让 Agent 安全碰到企业真实数据、并且敢放它动手,谁就拿走红利,跟谁家模型多几个 B 参数没关系。

当然,这只是 Ghodsi 这个坐标系里的故事,屁股决定脑袋的成分不能忽略,卖地基的人当然希望你相信地基才是胜负手。同一场峰会上,OpenAI 联合创始人 Greg Brockman 就轻轻顶了一句:“AGI 更像一种感觉,不是个有定义的东西。现在是当 builder 最好的时代。”一个站在应用基础设施这头,一个站在模型那头,两边对“AGI 到没到”的答案,本就取决于你站哪。

但有一点,无论你信不信 AGI 已来,都成立:下一轮竞争的胜负手,正在从“谁的模型更强”悄悄挪到“谁能让 AI 在公司里真的上班”。模型这几年一直是聚光灯的中心,而真正决定这波 AI 能不能变成钱的,可能是那些根本不发布参数、只忙着把数据接进 Agent 的人。

地基的活儿不性感,但楼盖多高,从来是地基说了算。

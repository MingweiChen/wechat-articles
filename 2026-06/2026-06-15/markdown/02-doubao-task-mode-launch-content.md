# 我打开豆包，今天的界面多了个按钮

我打开豆包，今天的界面不一样了。

输入框右下角，多了一个浅蓝色的小图标，叫「任务模式」。点进去，提示语从「问我点什么吧」换成了一行：「告诉我你的目的，我去办」。

这是 6 月 15 日。字节正式给豆包推了「任务模式」（Task Mode），三大能力：多轮搜索、深度推理、浏览器自动化。

按照 QuestMobile 的口径，豆包 2026 Q1 月活 3.45 亿，是中国月活最大的 AI 原生应用。今天有 3.45 亿人，会陆陆续续在某个时间点打开 App，然后看到一件事：这个聊天助手第一次长出了「腿」。

## 我让它办了一件复杂的事

测试发布会的最好方式，是真给它派活。我提了一个对我而言挺烦的需求：「帮我对比一下 6 月有上市发布会的国产新能源车，按落地价、续航、智驾水平拉个表，重点看 20 万级别。」

放在过去，豆包会输出一段「您可以参考以下信息」式的总结，然后留下几条让我自己去查的链接。今天它没这么干。它先回了一句「在做」，然后界面下方开始滚动出一个浅灰色的小窗，逐行显示它在做什么：

*（任务窗口里依次滚动出来的执行日志）*

- 正在搜索「2026 年 6 月 国产新能源车 上市」 → 找到 14 篇相关报道
- 正在筛选 20 万级别 → 命中 6 个车型
- 正在打开易车网 / 懂车帝 → 抓取落地价
- 正在交叉验证厂商官方公告 → 修正 2 处差异
- 正在整理表格

整个过程大约 90 秒。最后它给我的，是一份 6 行 4 列的对比表，每一项右上角带小角标，点开是它引用的原始网页。更微妙的是，它在表格底下补了一句：「比亚迪海豹 06 的『智驾水平』在不同信源上有歧义，官方页与媒体评测描述不一致，我倾向以官方页为准。」

它在告诉我，它干完活了，并且对自己干的活有判断。这件事不是「AI 答了一道题」，是「AI 替我跑了一趟腿」。

## 它和 ChatGPT 的 Deep Research 像吗

像，也不像。像的部分：都是 Agent 化能力，不是单轮回答，而是多步规划、调用工具、自我评估、修正、汇总。不像的部分，要看它服务的人群。

OpenAI 的 Deep Research 说服我，但豆包说服我妈。

这不是俏皮话。我妈 58 岁，前几天问我「网上传那个网红主播是不是真的破产了」，她在抖音上看到刷屏视频，想求证。如果这个时候她手里有今天的豆包，她可以打开任务模式，输入这句话，让豆包去搜各路媒体报道、官方声明、当事人回应、评论区原文，然后给她一个「这条信息可信度大概多少、来源是哪些」的回应。

她不需要懂什么 prompt engineering，不需要切换浏览器标签，不需要自己交叉验证。豆包做的事，本质上是把一个 Agent 装进了一个「我妈也会用」的入口里。

## 为什么是今天发

这是我看完发布会后，问自己的第二个问题。字节自己给的官方说辞是「技术成熟到了一个节点」。但凡做产品的都知道这句话太空——技术成熟是一条曲线，发布日期是曲线上的一个点，那个点为什么是今天。

我把它和另一件事拼在一起看：豆包月底（6 月下旬）要上线付费订阅。免费、68 元/月、200 元/月、500 元/月，四档。这两件事中间隔了 10 天。

所以「任务模式」的真正发布对象，可能不只是用户，更是用户的钱包。它要解决一个微妙的命题：让一个习惯了「AI 是免费的」的中国用户，愿意每个月掏 68 块、200 块、甚至 500 块续费。

让用户掏钱的逻辑，过去几年我们见了太多不成立的版本。便宜不是理由，免费替代品太多。功能堆叠不是理由，用户记不住。情怀不是理由，AI 没情怀。

真正能让人续费的逻辑只有一种：「这件事我不付钱就办不了」。「任务模式」就是那个「办不了的事」——免费用户能问豆包「介绍一下黄仁勋」，付费用户能让豆包「帮我按价格抓 5 家做储能的公司、整理财报、找 CEO 公开演讲、写一份 800 字的产业地图」。

后者是劳动力，前者是百科全书。劳动力可以收钱，百科全书不能。

## 海外是 Codex，国内是「数字小白领」

这是另一个我在比较中觉得有意思的点。如果你看 OpenAI 这边，过去 12 个月最重的产品演进是 Codex，把 ChatGPT 装进 IDE，让它给程序员写代码。Codex 周活官方披露过 500 万。Anthropic 那边更直白，Claude Code 直接做成 CLI，只服务程序员、产品经理、技术写作者。海外大厂的 Agent 路线，整体是「往专业用户走」。

字节这边显然走的是另一条路。豆包的定位从一开始就是「让普通人也能用 AI」，不是 IDE 插件，不是 CLI，不是 SaaS 工具——它是一个 App，你在抖音里能看到入口，长辈能下载，初中生能用。它的「任务模式」也不是给程序员设计的：程序员有 Cursor、有 Claude Code、有 GitHub Copilot；豆包的 3.45 亿月活里，绝大部分不是程序员。

这两条路的差别有点像 90 年代的两种电脑：一种是工程师的 Sun 工作站，一种是 Windows 95。

工程师的工具，单价高、用户少、深度用、ROI 清晰。普通人的工具，单价低、用户多、浅度用、要靠规模摊薄成本。

字节走 Windows 95 那条路，是因为它有 3.45 亿月活的入口护城河——这个量级，海外几家加起来都打不过。它把 Agent 能力装进这个入口里，等于把「自动办事」这件事民主化到普通人手里。

这事不是「字节赶上了海外」，而是中国 AI 产品在选另一条产品哲学：不是给精英用户的高单价工具，是给普通人的低单价仆人。

## 顺这条线推下去

如果「任务模式」+ 付费订阅这件事跑通，会发生什么。我顺着这条线推：

第一年看的是「AI 助手能不能挣到钱」。3.45 亿月活，假设 1% 转付费、人均 68 元/月，年化收入级别 28 亿元。这是个不错的数字，但还达不到「重塑商业模式」。需要看 2027 年的留存。

第二年看的是「AI 助手能不能取代搜索框」。任务模式真正成立后，豆包不再是「百度的替代品」，而是「百度 + 携程 + 美团 + 工具型 SaaS 的替代品」。这个时候它的对手不是 Kimi、不是元宝，而是百度本身、是抖音搜索本身——这是字节内部的赛跑。

第三年才轮到产业问题。当 AI 助手真的能办事，谁帮 AI「办事」？是那些被 Agent 调用的网站、API、工具。一批新中间件会冒出来，专门给 Agent 做「读得懂的网页」「调得通的接口」——这是另一个故事。

但这都是后话。今天值得记的只有一件：6 月 15 日，3.45 亿月活的豆包，第一次能替你跑腿。

## 给你看一组数字

最后留一组数字，作为今天的注脚。

按字节自己最近一次披露：

豆包大模型日均 Token 调用量 50 万亿，同比增长 10 倍。
累计 Token 使用超万亿的企业客户超 100 家。
对比海外，OpenAI Codex 周活 500 万。

要注意，Token 数和用户数不能直接换算。50 万亿 Token 里大量来自企业 API 调用，不是 C 端聊天。但即便保守折算，豆包 C 端的调用强度，仍然在数量级上和海外拉开了距离。

这个数量级差距，决定了豆包在「任务模式」这件事上有一个海外同行没有的优势：**用户基数大到可以摊薄 Agent 调用成本**。每一次「任务模式」的浏览器自动化，背后是真金白银的算力支出。免费用户跑得越多，平均成本越低，付费用户的边际利润越高。

这是规模生意才能玩的逻辑。

如果你身边有还在把豆包当成「AI 版百度」用的朋友，转给他看看。今天起，它不只是回答问题的，它能办事了。

# 微信公众号文章 HTML

存放微信公众号兼容的 HTML 文章代码。

## 使用方法

1. 复制 `.html` 文件内容
2. 在公众号后台编辑器中，切换到「HTML 模式」
3. 粘贴代码
4. 切换回可视化模式预览效果

## 注意事项

- 所有样式均为内联样式（微信不支持 `<style>` 标签）
- 图片需上传至微信图床后替换链接
- 外链仅支持公众号文章和小程序

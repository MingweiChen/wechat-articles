Anthropic 估值 9650 亿反超 OpenAI
Sam Altman 被迫 7 天跟交 IPO

AI 双雄 IPO 竞速：先发的人定规则，后发的人交学费

二月份，3800亿美元。

五月底，9650亿美元。

三个月，估值翻 2.5 倍。

更刺激的是另一组数字——OpenAI 三月份估值 8520亿美元。

Anthropic 反超了。1100亿美元的差距，靠一笔 Series H 一脚踩死。

紧接着，6月1日，Anthropic 向 SEC 秘密递交 S-1。

7天后，6月8日，OpenAI 跟着递。

一个抢跑，一个被迫跟随。

D.A. Davidson 分析师 Gil Luria 一句话点破："两家在抢空发资本市场。"

故事，从这里开始。

01 9650亿反超：3个月翻2.5倍的估值狂飙

先把这条估值曲线看清楚。

二月，Anthropic 估值 3800亿美元。

五月29日，Series H 收官，融资 650亿美元，投后估值 9650亿美元。

领投阵容是华尔街顶级配置：Altimeter、Dragoneer、Greenoaks、Sequoia、Capital Group、Coatue、D1。

七家头部基金，一起把 Anthropic 抬过 OpenAI。

支撑这套估值的，是营收。

年初，Anthropic 年化营收 90亿美元。

到五月，这个数字变成 470亿美元。

半年不到，4倍。

这不是 PPT 增长，是真金白银的 ARR。

更关键的对比在这里——

OpenAI 三月份完成融资 1220亿美元，估值 8520亿美元。

Anthropic 用了 3个月，把自己从 OpenAI 的零头，抬到 OpenAI 的上面。

一级市场不做局，做局的是基本面。

七家头部基金不是慈善家。他们看到的，是企业 API 调用量、是 Claude Code 的订阅曲线、是财富 500 强的采购订单。

02 抢跑IPO：6月1日 vs 6月8日的7天差距

时间线非常微妙。

6月1日，Anthropic 向 SEC 秘密递交 S-1 注册声明。

6月8日，OpenAI 跟进，秘密递交 IPO 申请。

中间隔了 7天。

这 7 天意味着什么？

意味着 Anthropic 是这场资本对决里主动出招的一方，OpenAI 是被动应战的一方。

Sam Altman 在 CNBC 采访里说："不专注于 IPO 时间。"

一句辩白，反而把"被迫跟随"四个字写在脸上。

资本市场最忌讳的，就是节奏被对手定义。

一位接近 OpenAI 的投资人对外表示，Anthropic 抢先递交 S-1，等于先把披露风险释放出来——OpenAI 之后再交，等于在免费看竞品的招股书。

这是一个非常残酷的判断。

招股书一旦秘密递交，监管沟通启动，财务、客户、风险因素、薪酬结构全部要交出去。Anthropic 走完一遍，等于把"AI 巨头如何定价、如何披露、监管想看什么"这套答案，先帮 OpenAI 摸清楚。

OpenAI 想跟，就只能跟 Anthropic 的节奏走。

先发的人定规则，后发的人交学费。

03 反超的真正引擎：Claude Code + 企业级AI

为什么 Anthropic 能反超？

不是营销，不是 KOL，不是 C 端故事。

是企业 API。

Anthropic 的 ARR 结构里，80% 来自企业 API。

OpenAI 反过来，60% 以上的收入来自 ChatGPT 订阅。

这是两条完全不同的商业模型。

订阅模型的天花板是用户数；API 模型的天花板是企业 IT 预算。

一个面对消费者，一个面对 CIO。

而真正的杀手锏，是 Claude Code。

这是 Anthropic 押在企业开发场景的核心引擎。它不只是一个代码助手，它是企业级 AI 编程工作流的底座——从代码生成、Code Review、再到 CI/CD 集成，Claude Code 切入了企业研发体系最核心的位置。

财富 500 强的开发团队，正在把 Claude Code 嵌入日常开发流程。每一行代码生成的背后，都是 token 消耗、是 ARR 增长。

更进一步，Anthropic 联合 Apple、Microsoft、Google、AWS、CrowdStrike、Palo Alto Networks，组建了一个叫 Project Glasswing 的 AI 安全联盟。

这个动作的含义远超"安全合作"——

它把 Anthropic 钉在了"企业级 AI 基础设施"的位置上。

Apple 不会和一个玩具型 AI 公司合作。AWS 不会和一个 to C 网红做联盟。

这些大厂愿意联手，本身就是估值的注脚。

04 OpenAI被迫跟随：Sam Altman 的尴尬时刻

Sam Altman 这一周不好过。

CNBC 镜头前，他说"不专注于 IPO 时间"。

潜台词大家都懂——节奏，已经不在他手里。

OpenAI 一直是 AI 行业的"先发者"。GPT-3、GPT-4、ChatGPT，每一次都是它定义节奏。

但这一次，先发权让出去了。

业内分析普遍认为，Anthropic 抢先递交 S-1，本质是抢叙事先机——

资本市场上市的故事，谁先讲，谁就是"AI 第一股"的候选人。

第二个递交的人，无论估值多高、营收多大，都要被打上"追赶者"的标签。

OpenAI 第一次，从领跑变成跟跑。

Dario Amodei 这边的剧本就完全不同。

据公开报道，Anthropic CEO Dario Amodei 个人身家约 70亿美元。他在过去多次公开场合强调"AI 安全"叙事，据报道曾抵制将 AI 用于大规模监控用途。

更关键的一步，Anthropic 把自己注册为 Public Benefit Corporation（公益公司）。

这个法律架构意味着，公司在追求利润之外，董事会有义务考虑公共利益。

一边讲商业增长，一边讲社会责任。

资本市场最爱的就是这种"既能赚钱又有道德资本"的故事。

OpenAI 的"非营利转营利"叙事，过去一年争议不断。Anthropic 这一手 PBC，等于直接绕开了这个雷区。

05 IPO双雄战的资本游戏

把所有信号串起来，画面就清晰了。

估值层面——

Anthropic：9650亿美元（5月29日） OpenAI：8520亿美元（3月）

Anthropic 反超 1100亿。

营收层面——

Anthropic：年化 470亿美元（80% 来自企业 API） OpenAI：年化数据未公开（60%+ 来自 ChatGPT 订阅）

两条增长曲线，方向完全不同。

资本节奏层面——

Anthropic：6月1日 S-1 OpenAI：6月8日 S-1

7天差距，Anthropic 主动，OpenAI 被动。

算力布局层面——

据报道，Anthropic 与 SpaceX 签订 450亿美元算力大单。

注意一个时间点：6月12日，SpaceX 上市。

Anthropic + SpaceX 的算力绑定，等于把"未来十年的 AI 基础设施"提前锁定。

生态层面——

Project Glasswing 拉来了 Apple、Microsoft、Google、AWS、CrowdStrike、Palo Alto。

OpenAI 这边，依然主要绑定在微软体系内。

法律架构层面——

Anthropic：Public Benefit Corporation OpenAI：从非营利转营利的争议未平

一组对比下来，Anthropic 不是侥幸反超，是体系化反超。

D.A. Davidson 的 Gil Luria 那句话再读一遍：

"两家在抢空发资本市场。"

这句话的潜台词是——

公开市场对 AI 的胃口是有限的。第一个吃饱的，会拿走最多的钱、最好的估值倍数、最强的二级流动性。

第二个，只能吃剩下的。

一个判断

这场反超，不是终点，是 AI 行业第二阶段的开场。

第一阶段，是 OpenAI 用 ChatGPT 教育市场。

第二阶段，是 Anthropic 用企业 API 吃掉利润。

C 端的故事好讲，B 端的钱好赚。前者抢用户，后者抢预算。

9650亿 vs 8520亿，不是一次性的估值倒挂，而是商业模式胜负的提前预演。

谁先把企业级 AI 做成基础设施，谁就拿到下一个十年。

7天的差距，看起来很小，但在资本市场里，这 7 天可能就是 2000 亿美元的二级市场溢价。

Sam Altman 的尴尬，不是输在产品上，是输在节奏被对手定义这件事上。

在 AI 这场牌局里，先发权第一次易主。

接下来要看的，是两份招股书最终披露的财务细节、是上市后的二级表现、是 Claude Code 和 ChatGPT 在企业市场的正面对决。

但有一件事可以确定——

Anthropic 已经不是那个"陪跑者"了。
